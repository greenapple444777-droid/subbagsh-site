# Excel → Word хөрвүүлэгч

Excel (`.xlsx`) файлыг **хүснэгтийн загварыг нь алдагдуулахгүйгээр** Word (`.docx`) болгоно.
Хуудас (sheet) бүр Word-ийн тусдаа хуудас/хэсэг болж, Excel-ийн хэвлэх тохиргоог дагана.

## Юуг хадгалдаг вэ

| Excel | Word-д |
|---|---|
| Нэгтгэсэн нүд (Merge) | Нэгтгэсэн нүд (хэвтээ, босоо) |
| Баганын өргөн, мөрийн өндөр | Яг тэр харьцаагаар |
| Хүрээ (нимгэн, зузаан, давхар, тасархай, өнгө) | Ижил хүрээ |
| Нүдний дэвсгэр өнгө (theme өнгө, tint орно) | Ижил өнгө |
| Фонт: нэр, хэмжээ, тод, налуу, зураас, өнгө, дээд/доод индекс | Ижил |
| Нүдэн доторх хэсэгчилсэн формат (rich text) | Ижил |
| Хэвтээ/босоо зэрэгцүүлэлт, догол, мөр шилжилт | Ижил |
| Эргүүлсэн (босоо) бичвэр | Босоо бичвэр |
| Тооны формат: `0.00`, `#,##0`, `%`, огноо, `0;-0;;@` | Excel-д харагдах утгаар |
| Томьёо | Бодогдсон утга |
| Нуусан мөр, багана | Алгасна |
| Хэвлэх муж (Print area) | Зөвхөн тэр мужийг |
| Хуудас бүрт давтах гарчиг мөр (Print titles) | Word-д ч хуудас бүрт давтагдана |
| Хэвтээ/босоо чиглэл, цаасны хэмжээ (A4, A3, A5, Letter), захын зай | Ижил |
| "Fit to page" / хуудсанд багтаах | Хүснэгтийг жигд жижигрүүлж багтаана |

Хадгалагдахгүй: Excel доторх зураг, график, нөхцөлт формат (conditional formatting).

## Апп (юу ч суулгахгүй)

`web/` хавтсанд хөтөч (Chrome, Edge, Firefox) дээр шууд ажилладаг апп бий:
`web/index.html`-г давхар дарж нээгээд Excel файлаа чирж оруулна → **"Word болгож татах"**.
Файл компьютерээс гарахгүй, хөтөч дотор хөрвүүлэгдэнэ (интернэт холболт номын сан ачаалахад л хэрэгтэй).
`web/` хавтсыг subbagsh.site дээр байршуулбал хэн ч хэрэглэж болно.

Хөтчийн апп томьёог дахин бодож чадахгүй: файл Excel-ээр хадгалагдсан бол утгууд гарна.

## Python хувилбар: суулгах (нэг удаа)

1. [Python](https://www.python.org/downloads/) суулгана (суулгахдаа **"Add Python to PATH"**-г чагтална).
2. Энэ хавтсыг компьютер дээрээ хуулна.

## Ашиглах

**Хамгийн хялбар:** `Хөрвүүлэх.bat` файлыг давхар дарна → цонх нээгдэнэ →
**"Excel файл сонгох…"** товч дарж нэг эсвэл хэд хэдэн файл сонгоно.
Word файл Excel файлтай нэг хавтсанд ижил нэртэй үүснэ.

Эсвэл Excel файлаа `Хөрвүүлэх.bat` дээр чирж тавихад шууд хөрвүүлнэ.

**Командын мөрөөр:**

```bash
pip install -r requirements.txt

python excel2word.py файл.xlsx                    # файл.docx үүснэ
python excel2word.py а.xlsx б.xlsx в.xlsx         # олон файл
python excel2word.py файл.xlsx -o гаралт.docx
python excel2word.py файл.xlsx --sheets "Нэгтгэл" "Бие бялдар"   # зөвхөн сонгосон хуудсууд
python excel2word.py файл.xlsx --no-fit           # жижигрүүлэхгүй, бодит хэмжээгээр
python excel2word.py файл.xlsx --keep-font-size   # зөвхөн баганыг жижигрүүлж, фонтыг хэвээр
```

## Анхаарах зүйл

- Хуучин `.xls` файлыг Excel-ээр нээгээд **Save As → .xlsx** болгоод хөрвүүлнэ.
- Томьёоны үр дүн файлд хадгалагдаагүй бол (жишээ нь программаар үүсгэсэн файл)
  LibreOffice суусан байвал автоматаар бодуулна. Үгүй бол файлаа Excel-ээр нээж,
  хадгалаад дахин хөрвүүлнэ.
- Хүснэгт хуудаснаас өргөн бол Excel-ийн хэвлэхтэй адил жигд жижигрүүлнэ.
  Хэдэн хувь болгосныг програм мэдээлнэ.
